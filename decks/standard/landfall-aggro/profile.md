# Mono-Green Landfall pilot profile

This profile accompanies the frozen Maxime Rayvich World Championship 32 list dated 2026-11-13. The deck is aggressive but can pivot between fast pressure, landfall combo turns, and a slower Sapling Nursery board. The external pilot chooses every action; Forge does not choose a line.

## Mulligans

Start from the pilot guide's heuristic: look for an early engine/acceleration play among Llanowar Elves, Sazh's Chocobo, and Carnivorous Cultivator, plus enough lands to operate. The guide describes a 12-card early-play threshold for its earlier 75. This current 60 has the same four-of trio, but the exact keep rule is an adaptation, not a tested rule for Maxime's list. Against a known slow deck, evaluate grind and card availability as well as the one-drop heuristic.

## Sequencing and priority

- Plan several turns ahead: decide whether the hand should race with Chocobo/Ascension, set up Icetill Explorer plus Mightform Harmonizer, or stabilize with Sapling Nursery.
- Sequence fetch lands and landfall triggers deliberately. When a Harmonizer doubling trigger is available, resolve counters from Chocobo/Ascension before the doubling trigger when that yields more power. Source S2 and S3 both describe this trigger-ordering principle.
- Preserve a usable fetch/landfall sequence for Icetill/Harmonizer turns. Check the current library and graveyard before committing to a line; do not assume a fetch target remains.
- Keep track of remaining Forests and other fetch targets. Avoid wasting a land drop when an engine can create a better later turn, unless immediate pressure or mana requires it.

## Combat and interaction

Calculate lethal from public power, landfall triggers, trample/evasion, and the exact number of available land entries. Make the role choice explicit: attack to race when the opponent's clock is faster; otherwise build a board or combo threat. The deck's main list has little conventional instant-speed interaction, so use the sideboard fight/removal cards to protect tempo and remove the key opposing threat rather than trading them without a plan.
